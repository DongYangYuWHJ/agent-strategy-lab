# 更大规模的真实仓库任务

当前优先执行无需额外系统环境的 [真实纯 Python 仓库任务](pure-python-repo-tasks.md)。下述八题保留为 Linux 容器路线的候选，不与已能运行的两题混为一组。

本轮从 [SWE-bench Pro V2](https://github.com/scaleapi/SWE-bench_Pro-os/tree/66f92766bba642462d4bbe5479e83f91f9211862/v2) 的 642 个任务中，人工选出 8 个开发集候选。固定上游提交 `66f92766bba642462d4bbe5479e83f91f9211862`，不使用按模型失败率筛出的 HARD-51。目标是扩大工程范围，而不是增加算法难度或挑选某个模型不能通过的题。

| 项目／任务 | 工程范围 | 参考实现代码文件数 |
|---|---|---:|
| Ansible：多服务器配置解析 | CLI、配置注册、默认值、必填选项和错误处理 | 4 |
| Open Library：图书奖提名后端 | API、身份验证、已读前置条件、提名增改删及数据模型 | 5 |
| Open Library：书目格式解析一致性 | XML／Binary 两条处理链、多文字作者和标题、已有字段保留 | 5 |
| Flipt：多种指标导出器 | 配置解码、Prometheus／OTLP、初始化生命周期、兼容默认行为 | 4 |
| Flipt：默认配置与 Schema 一致性 | CUE 校验、类型转换、可选配置、存储与认证设置 | 4 |
| Navidrome：数据库备份与恢复 | CLI、配置、在线 SQLite 备份、恢复、文件保留策略 | 5 |
| NodeBB：聊天隐私名单 | 前后端设置、消息权限、管理员例外、数据迁移 | 6 |
| NodeBB：邮件确认 | 过期／重发流程、管理接口、Mongo／Postgres／Redis 适配 | 7 |

文件数根据参考补丁统计 `.py/.go/.ts/.tsx/.js/.jsx`，排除路径包含 test/spec/snapshot/lock/changelog 的文件；属于操作者粗略规模指标，不是模型必须修改的文件数，不代表完整仓库文件数，也不是实测难度。八题涉及五个真实项目和 Python、Go、JavaScript。样本是人工工程类型选择，不代表整个基准的随机样本。

## 已准备的材料

- [固定清单](../benchmarks/swebench-pro-v2-selection/selection.json)：原始 instance ID、上游版本、需求文件校验和、参考补丁规模；不是当前运行器的 task.json。
- [准备脚本](../scripts/prepare_upstream_repo_tasks.py)：仅用 Python 标准库下载固定版本，核验压缩包与需求校验和，保存所选原始说明、环境定义、验收器和参考补丁。不会安装依赖、运行上游脚本或调用模型。
- 本机材料与逐文件校验回执：`artifacts/swebench-pro-v2-intake/operator/` 和 `receipt.json`，由 Git 忽略。上游许可和说明保存在 `provenance/`；使用时还需遵守各项目许可。

重新准备：

```powershell
.\.venv\Scripts\python.exe scripts/prepare_upstream_repo_tasks.py
```

**整个 operator 目录包含答案与隐藏测试，禁止给 Agent 挂载或作为文件工具根目录。** 正式输入只应包含原始需求与容器内基准版本仓库；模型可以自主探索、修改并执行允许的开发测试。不要通过参考补丁生成可编辑文件白名单，避免泄漏定位信息。输出为代码差异及四轮对话轨迹。最终验收将补丁应用到新环境后执行原验收器，隐藏测试不进入修复反馈。

## 当前状态与运行缺口

目前完成任务筛选和材料准备，**尚未接入本地运行器，也未进行付费测试**。下载的是任务包，不是五个项目的完整源码与依赖；上游将基准仓库和依赖放在每题的 Linux 容器镜像中。

本机未发现 Docker 命令。现有实验使用小目录、固定 app.run 输入输出及有限文件工具，不能直接运行这些完整项目。还需接入容器内 OpenCode／工具执行、补丁提取和独立验收，保留会话、权限隔离和费用计量。不能只把这里的 instruction.md 塞进原实验配置就宣称兼容。

接入后先在所选任务上做无模型的原始代码失败／参考补丁通过检查，确认安装、服务和验收时间稳定，再跑单体比较。上游参考验证不替代我们本机验证。继续允许 Agent 测试和返工；实现轮结束保存首次交付快照，最终交付另存，以离线验收比较质量与修复成本。八题全部先作开发集，尚未建立保留评估集。
