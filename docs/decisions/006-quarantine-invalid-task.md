## 观察

扩充任务的首次正负对照审计中，候选 `abc392_f / Insert` 的正对照通过公开样例，却在隐藏输入上异常退出。定位发现第 15 个隐藏输入给出 `N=6`、第一步 `P_1=3`，违反题面 `1 <= P_i <= i` 的约束。

该问题由接入前的离线数据／验收审计发现，没有根据 DeepSeek 或 Luna 在该题上的成绩作筛选。

## 决定与变化

## 学到的方法与验证

外部 benchmark 也是需要检查的数据。正对照失败时，应区分参考实现错误、输入不合法、评分语义不符和环境故障，不能直接认定题目很难或模型能力不足。

任务排除应采用与模型胜负无关的标准，并公开记录理由；否则容易通过挑题影响实验结果。本次最终 18 题全部通过正负对照审计，但这仍不证明未发现的上游问题已经不存在。
