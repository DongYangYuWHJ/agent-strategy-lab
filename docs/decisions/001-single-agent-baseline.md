# 001：先建立单 Agent 基线

记录日期：2026-10-21，回顾性补记。状态：已采用，持续执行。

## 背景与决定

项目希望验证不同模型分工和协作结构的质量、成本与稳定性。为了能够解释后来的协作收益，先测量单 Agent 在固定任务、工具和验收下的表现，再引入规划与交接。

模型初筛因此也是第一轮单 Agent 实验。先用固定回放检查框架，再用真实 API 检查工具循环和计量；模拟结果不参与模型能力排名。

## 计划变化及方法依据

近期关注点收敛到任务覆盖、输入输出约定、独立验收和模型参数特征。投票督察、复杂升级策略和多 Agent 架构比较保留为后续研究议题。

这借鉴基线和控制变量的实验原则。若任务、工具、模型和重试策略一起变化，就很难判断交付变化来自哪里。单模型经过合理调参的方案，也应成为未来协作方案的对照，避免拿未经校准的弱基线比较。

## 已有证据与边界

原生 runner 已实现单 Agent 工具循环、停止条件、独立验收和费用记录；真实模型已完成小型任务和部分重复费用测试。现阶段样本量和任务种类仍有限，不能从某次单题成绩推导稳定模型职责。

未来不必等待所有模型和参数都被穷尽。具备代表性基线、可解释的失败分类和可冻结的测量条件后，就可以开展结构实验；具体准入条件仍需另行确定。
