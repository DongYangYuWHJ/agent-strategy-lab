# Pure Python repository upgrades v1

Two curated development tasks built from fixed TinyDB and ItsDangerous source.
No Docker, Linux, package installation or pytest is needed for lab acceptance.
This is not an official upstream benchmark or a collection of original issues.

See [scope, provenance, limitations and commands](../../docs/pure-python-repo-tasks.md).
Every source tree preserves upstream license files. Original upstream pytest
tests remain readable, but are not represented as having run in this lab.

`operator/` directories contain reference implementations and incomplete fixes.
They must never be exposed to solving agents. Task adapters are immutable; all
library package modules are editable. Hidden grading remains outside source.
